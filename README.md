# ModBot

Небольшой бот для модерации групп Telegram. Права проверяются по правам администратора Telegram: бот не даст забанить, замутить или кикнуть участника, если у администратора нет соответствующего разрешения. Самому боту также нужны права администратора.

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Впишите токен из `@BotFather` в `.env`, добавьте бота в группу администратором и выключите Privacy Mode в BotFather (`/setprivacy`), чтобы команды и ответы на сообщения доходили до бота.

```powershell
python bot.py
```

## Команды

| Команда | Действие |
| --- | --- |
| `/ban [причина]` | Бан ответом на сообщение |
| `/unban <id>` | Разбан по Telegram ID |
| `/mute 30m [причина]` | Мут: `15m`, `2h`, `3d`; без времени — 1 час |
| `/unmute` | Снять мут ответом на сообщение |
| `/kick [причина]` | Удалить из группы без бана |
| `/warn [причина]` | Предупреждение, на 3-м — бан |
| `/unwarn` | Снять последнее предупреждение |
| `/warnings` | Посмотреть предупреждения участника |
| `/purge` | Удалить сообщения, начиная с того, на которое ответили |
| `/rules` | Вывести правила (задаются в `bot.py`) |

`/help` выводит команды прямо в Telegram.
